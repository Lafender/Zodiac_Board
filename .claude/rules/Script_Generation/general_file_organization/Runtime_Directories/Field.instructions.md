<directory_name>

Field

</directory_name>

<directory_description>

Contains all scripts running the action content of the game. This mainly means taking input from the Player during stages of the game not spent in Menus or Dialogs, and animating the game based on that input and game data. It controls all collisions and  animations linked in the `res://Character/` folder to character/npc/enemy-specific `res://Race` animations and Card-based skills from `res://Items/`, and links in the calculators from `res://Chemistry/`, `res://Statistic/`, Job_Pages from `res://Item/`.

Like all other folders it can also use files and objects in `res://Common/`.

</directory_description>
